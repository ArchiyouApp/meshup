THIRD-PARTY NOTICES for meshup (@archiyou/meshup)
=================================================

meshup itself is licensed under the Apache License 2.0 (see LICENSE).

meshup ships a WebAssembly binary compiled from the Rust crate in `rust/`. That
binary is embedded as a base64 string in `src/meshup-js-binary.ts` and is
consequently also contained in the published bundle `dist/index.js`. It links in
the third-party Rust crates listed below, so every distribution of this npm
package is also a distribution of those works.

The Rust source tree itself is not published to npm; it lives at
https://github.com/ArchiyouApp/meshup.

3. Rust crates from crates.io
-------------------------------------------------------------------------------
Notable direct dependencies linked into the WebAssembly binary. All are
distributed under permissive MIT, Apache-2.0, MIT-OR-Apache-2.0 or BSD/ISC-family
terms; no copyleft dependency is present.

    nalgebra, geo, robust, spade, earcutr, chull, boolmesh, curvo,

    stl_io, dxf, roxmltree, zip, gltf, image, fast-surface-nets,
    contour_tracing, wasm-bindgen, js-sys, web-sys

For the authoritative, per-version list of every transitive crate and its
license, run in the meshup Rust tree:

    cd rust && cargo deny check licenses

Cargo.lock does not carry license metadata, so that command — not this file — is
the source of truth for the full transitive set.
